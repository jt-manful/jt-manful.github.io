About

I started as a software engineer, building APIs and full stack features in Agile teams at Turntabl and at Ashesi University. The stack was Spring Boot, Django REST Framework, React, Azure and AWS, with a lot of testing along the way.

Robotics came in through Ashesi, where I worked on research team developing a ROS based service robot. Now I am doing an M.Sc. at the University of Bonn specialising in Intelligent Systems and exploring how AI, robot learning, and computer vision can enable robots to perceive, reason, and act in the real world.

I enjoy working on problems that bring software and robotics together, from building the systems behind an application to getting a model to work on a real robot.

Selected works

Lab project

Vision language action models for bimanual manipulation

Cognitive Robotics Lab, University of Bonn

I fine tuned and compared two VLA models, π0.5 and X-VLA, on a bimanual robot platform for two tasks: brick placement and multi stage bottle opening.

  • Built the layer between data, models and robot: LeRobot dataset conversion, action space registration, and a FastAPI policy server and client for real robot and MuJoCo rollouts.
  • π0.5 reached 90% success on brick placement and 20% full task success on bottle opening.
  • Alignment with a model's pretrained action space was a key factor in the performance gap between the two models.

Openpi (π0.5) / X-VLA / LeRobot / MuJoCo / FastAPI / Python

Repository on GitHub

Simulation

ROS 2 mobile robot: mapping and navigation

A simulated mobile robot with a two axis arm that maps an unknown environment and navigates it autonomously.

  • SLAM Toolbox builds the map in real time, and Nav2 handles path planning and obstacle avoidance.
  • The robot is described in URDF/Xacro and simulated in Gazebo, with state, map and trajectories shown in RViz2.

ROS 2 / Nav2 / SLAM Toolbox / Gazebo / RViz2

Repository on GitHub

Ongoing

Lunar Lander: reward engineering for reinforcement learning

A reinforcement learning project investigating how reward design influences learning efficiency, training stability, and autonomous spacecraft landing performance in Gymnasium's LunarLander-v3 environment.

  • Implements tabular Q-learning and Proximal Policy Optimization (PPO) to train and evaluate autonomous landing policies.
  • Planned experiments compare reward-shaping strategies using learning curves, landing success rates, crash frequency, and touchdown conditions across multiple random seeds.

Python / Gymnasium / Q-learning / PPO / Stable-Baselines3 / uv

Repository on GitHub

Detecting fraudulent crypto platforms with machine learning

Undergraduate thesis, Ashesi University, IEEE

An ensemble of Random Forest and LightGBM that reached 96.2% classification accuracy.

  • Engineered features from certificate security signals, WHOIS metadata and aggregated user review sentiment.
